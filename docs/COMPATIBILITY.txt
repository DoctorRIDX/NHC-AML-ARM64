COMPATIBILITY NOTES

From the supplied AndroidModLoader-main.zip:
- README says AML is a native mod loader and must be loaded after game libraries.
- AML mod template uses MYMOD / ON_MOD_LOAD callbacks.
- AML root Application.mk supports armeabi-v7a and arm64-v8a.
- The default template_of_mod/Application.mk supplied by the source was
  armeabi-v7a only; this project sets APP_ABI := arm64-v8a.
- AML documentation places mods in /sdcard/Android/data/<game.package>/mods/
  or an AML internal mods directory, depending on loader setup.

External SDK compatibility:
- Official AML Plugin SDK currently lists GTA SA v2.00 and GTA SA v2.10 (64-bit).
- GTA SA 2.11.311 is not listed. Therefore runtime compatibility is unverified.

Build status:
- This workflow is intended to compile the NHC loader-test plugin.
- A successful compile is not proof that the game can load AML or NHC.
